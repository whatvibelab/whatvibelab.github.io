친구와 결과가 달라도 괜찮아요 — 결과로 대화를 시작하는 질문 20개

이용 가이드2026.09.21 · 읽는 시간 약 4분

재미로 보는 테스트예요. 심리검사가 아니에요.

요약

결과 카드를 주고받고 나면 "오, 신기하다" 하고 끝나기 쉬워요. 결과를 이야기의 시작으로 쓰면 같은 테스트도 훨씬 오래 재미있어요. 아래 20개 질문은 결과, 궁합, 질문 장면, 나도 몰랐던 나, 이어서 해볼 것의 다섯 가지 방향으로 나눴어요. 마음에 드는 것만 골라서 써 보세요.

먼저, 대화의 약속 세 가지

  1. 결과는 이야기의 재료일 뿐이에요. 재미로 즐기는 테스트라서 사람을 평가하거나 판단하는 근거가 아니에요.
  2. 놀림은 하지 않아요. 외모, 성별, 사생활을 결과에 엮어서 놀리지 않고, 상대가 불편해하면 바로 멈춰요.
  3. 보여 주고 싶지 않다면 안 보여 줘도 돼요. 결과를 공유할지는 각자가 정해요.

A. 내 결과 이야기하기 (4개)

  1. 결과 설명에서 "맞아, 나 이래!" 싶은 문장이 어디였어?
  2. 반대로 "이건 좀 아닌데?" 싶은 부분은 어디야? 그 부분은 어떤 상황에서만 다른 모습이야?
  3. 한 줄 요약(태그라인) 중에 평소 내 입버릇과 닮은 말이 있어?
  4. 특징 세 가지 중에 친구가 보기에 가장 나다운 건 뭐라고 생각해?

B. 궁합 짝으로 이야기하기 (4개)

결과 화면에는 "잘 맞는 궁합"으로 다른 결과가 하나 나와요. 이 짝은 비슷한 결과가 아니라 서로 다른 점이 채워지는 쪽으로 정해져 있어서 이야기하기 좋아요. 예를 들어 카페 음료 테스트에서 아메리카노와 딸기라떼가, 고양이 테스트에서 시크한 올블랙냥이와 호기심 대장 삼색냥이가 서로의 짝이에요.

  1. 내 궁합 결과가 누구일 것 같아? 주변에 진짜 그런 사람이 있어?
  2. 우리 둘의 결과가 서로의 짝이라면 어떤 점이 잘 맞을까? 짝이 아니라면 어떤 점이 서로 다를까?
  3. 우리 모임에서 같은 결과가 나온 사람이 있어? 같은 결과인데 다르게 답한 부분도 있어?
  4. 궁합 짝이 나온 친구와 같이 하면 재미있을 일은 뭐가 있을까?

C. 질문 장면 되짚어 보기 (4개)

테스트의 질문 하나를 골라 서로 어떤 쪽을 선택했는지 물어보는 방법이에요. 같은 질문에서 다른 선택을 한 걸 발견하는 순간이 가장 재미있어요.

  1. (조원 테스트) "마감 전날이 됐다. 나는?" — 이미 끝내 두고 마지막 검토를 한다 / 이때부터 본격적으로 속도가 붙는다. 지난번 팀플에서는 어땠어?
  2. (카페 음료 테스트) "메뉴판을 볼 때 나는?" — 먹어본 익숙한 메뉴부터 확인한다 / 처음 보는 특이한 메뉴에 눈이 먼저 간다. 오늘은 어느 쪽이었어?
  3. (설기 테스트) "가려던 떡집이 문을 닫았다. 나는?" — 미리 알아본 대안 매장으로 바로 이동한다 / 그 근처에서 즉흥적으로 다른 곳을 찾아본다. 여행에서도 그랬던 적 있어?
  4. (답장 테스트) "메시지 알림이 떴다. 나는?" — 바로 읽고 답할 내용을 정리한다 / "나중에 봐야지" 하고 두다가 잊는다. 서로의 답장 속도는 어때?

D. 나도 몰랐던 나 찾기 (4개)

  1. 답하면서 가장 오래 고민한 질문이 뭐였어? 마지막까지 고민한 두 선택지는?
  2. 기분이 좋은 날과 지친 날 같은 테스트를 하면 결과가 달라질 것 같아?
  3. 결과 이름이 마음에 들어? 마음에 안 든다면 어떤 결과였으면 했어?
  4. 우리 팀이나 가족에게 이 결과를 붙인다면 누가 어떤 결과일 것 같아? (서로 동의한 경우에만 해 봐요)

E. 이어서 해볼 것 정하기 (4개)

  1. 고양이 테스트를 하기 전에 내가 무슨 고양이일지 먼저 예상해 볼래? 하고 나서 예상과 비교해 봐요.
  2. 서로의 결과를 맞혀 보는 게임을 해 볼까? 친구가 어떤 답을 했을지 상상하며 내가 대신 고른 뒤, 실제 결과와 비교해요.
  3. 다음에 카페에 가면 카페 음료 테스트 결과 카드를 보여 주고 같은 결과가 나온 음료를 주문해 볼래?
  4. 오늘 나온 결과 카드를 저장해 두었다가 한 달 뒤에 다시 해 보고 달라졌는지 비교해 볼래?

이렇게 활용해 보세요

  • 모임 자리라면 A와 C 질문을 섞어서 한 사람씩 돌아가며 물어보세요. 결과 카드를 화면에 띄워 놓고 이야기하면 더 재미있어요.
  • 채팅으로 이야기한다면 B와 E가 잘 어울려요. 결과 링크를 함께 보내면 친구가 바로 자기 결과를 해 볼 수 있어요.
  • 결과가 마음에 들지 않아도 괜찮아요. "이건 나 같지 않은데?"라고 생각하는 지점이 오히려 나를 더 잘 설명해 주는 이야기가 될 때도 많아요.

결과 카드를 저장하고 링크로 보내는 방법은 결과 이미지 카드 저장하고 공유하는 법에서 볼 수 있어요. 지금 바로 시작하고 싶다면 나는 어떤 카페 음료일까?, 나는 어떤 조원일까?, 나는 어떤 고양이일까?로 가볍게 시작해 보세요.
